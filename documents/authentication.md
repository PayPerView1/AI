# Authentication & Registration

To access the platform, users must create an account and verify their identity. We offer separate sign-up flows for Brands and Clippers to ensure tailored onboarding.

## Sign Up Flow
1. **Email & Password:** Enter a valid email address and secure password.
2. **Account Type Selection:** Choose either "Brand" or "Clipper". This choice is permanent and cannot be changed later.
3. **Email Verification:** A 6-digit verification code is sent to the registered email. Users must enter this code within 15 minutes to activate their account.

## Login & Security
- **Multi-Factor Authentication (MFA):** Recommended for all users and mandatory for Brands managing budgets over $5,000. MFA can be configured via Google Authenticator or SMS.
- **Password Resets:** Users can request a password reset link via the "Forgot Password" option on the login page. Reset tokens expire after 1 hour.
- **Session Management:** Sessions are valid for 30 days. Accounts with suspicious login attempts from multiple locations will be temporarily locked.
